# 嗅辨溯源 · 移动端 MVP

用"人的嗅觉 + 手机定位 + 当地气象"粗略反推污染源方位，不依赖浓度监测数据。

## 在线使用（推荐）

手机浏览器直接打开：**https://lfc0902.github.io/odor-source-mobile/**

- HTTPS 页面，手机可以正常弹出定位授权，天气、地图都不依赖电脑。
- 添加到主屏幕即可像 App 一样全屏使用：
  - Android Chrome / Edge：菜单 →「添加到主屏幕」/「安装应用」
  - iPhone Safari：分享 →「添加到主屏幕」
- 首次打开需要联网；之后页面壳会离线缓存（地图瓦片和天气仍需网络）。

## 本地启动（开发用）

双击项目根目录的 `启动手机版.bat`，然后：

- 电脑本机：http://localhost:8123
- 手机（同一 Wi-Fi）：http://电脑局域网IP:8123

电脑 IP 用 `ipconfig` 查看（IPv4 地址）。首次运行 Windows 防火墙可能弹窗，选"允许"。

## 使用流程

1. 打开页面 → 自动定位（或点击地图手动标点）
2. 自动显示当地天气：风向、风速、气温、湿度
   - 主源 Open-Meteo（免 key，8 秒超时）→ 失败自动切 wttr.in（12 秒）
   - 两个源都失败时，点「手动」输入风向（0–359°）和风速（m/s）继续使用
3. 按当下闻到的情况选择气味等级 1–5
4. 点击「提交嗅辨记录」→ 地图上画出**上风向扇形**和**估算位置圈**
5. 换几个位置重复提交，多个扇形交叠处即最可能的污染源区域

## 定位不准怎么办

页面会显示定位精度（± 米）。连续采样 8 秒取最准的一次，精度 ≤ 20 米自动结束。

1. **手机系统里允许「精确位置」**：Android 12+/iOS 13+ 的定位授权有「精确 / 大致」开关，网页拿不到精确位置时误差可达公里级。
2. **不要用微信内置浏览器打开**：微信 WebView 常用网络定位，误差大且可能返回高德 GCJ 坐标。点右上角「…」→「在浏览器打开」。
3. **一键校准**：如果蓝点与真实位置有稳定的偏移（常见是约 500–600 米，方向基本一致，多为设备返回 GCJ 坐标被再次转换），点「校准」，再在地图上点一下你此刻的真实位置。偏移会保存在本机，之后自动修正；按「清除校准」可恢复。
4. 临时使用可直接点地图任意位置手动标点（显示「手动标点」）。

## 关键点

- **手机定位需要 HTTPS**。局域网 `http://IP:8123` 下浏览器不会弹出定位授权，此时点地图手动标点即可，天气与溯源功能不受影响。（要真机自动定位，需要 HTTPS 隧道或打包成 APK 使用原生定位。）
- **地图坐标系**：高德瓦片是 GCJ-02，手机 GPS 是 WGS-84。`js/coords.js` 做了双向转换：内部几何计算全部用 WGS-84，只在绘制和点击时转换，实测误差 < 1 米（`test/coords.test.js`）。
- 高德瓦片为演示用非官方直连；正式发布请改用**高德 JS API（申请免费 key）**，避免版权/授权问题。
- 扇形半角、各气味等级对应的距离区间都在 `js/app.js` 顶部的 `CONFIG` 里，可按实测标定。

## 自测

```bash
# 需先启动静态服务（8123）
node test/geo.test.js      # 球面几何：方位/距离/扇形顶点
node test/coords.test.js   # WGS-84 <-> GCJ-02 转换与往返精度
node test/e2e_cdp.js       # 端到端：390x844 视口 → 定位 → 真调天气 → 提交 → 手动风 → 兜底模拟
```

`e2e_cdp.js` 会自动启动 headless Edge（每次独立调试端口、结束时杀进程树），
产出 `_e2e_before.png` / `_e2e_after.png` / `_e2e_manual.png`。
测试 GitHub Pages 线上版：`BASE_URL="https://lfc0902.github.io/odor-source-mobile/" node test/e2e_cdp.js`。
